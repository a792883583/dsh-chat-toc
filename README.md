# dsh-chat-toc

[English](README.en.md) · [Español](README.es.md)

DSH Web GUI 的对话目录增强插件：深度赋能官方原生 Turn Rail 导航轨，不再生成重复多余轨道；提供全局快捷键、实时搜索、消息收藏与 Markdown 大纲导出。

## 功能

- **原生融合赋能**：完美依附并增强 DSH 原生 Turn Rail 导航轨，彻底告别双轨并排的拥挤感，界面 100% 干净清爽
- **全局快捷键呼出**：支持按下 `Cmd/Ctrl + Shift + O` 随时呼出、收起或固定完整大纲面板，或者点击轨道顶部的精致大纲小按钮
- **智能结构化标题提取**：优先提取 Markdown 二级/三级标题（`##`）与加粗核心要点作为目录项摘要，让技术长文和多阶段对话大纲层次分明
- **一键固定面板（Pin）**：支持将展开的大纲固定在右侧，方便持续对照长文与方案
- **目录搜索与快速跳转**：大纲顶部提供实时搜索框，按消息摘要快速过滤，点击平滑滚动跳转至对应消息
- **消息收藏（⭐）**：悬停任意目录项点击星标快速收藏关键结论与协议，支持「仅看收藏」视图，持久化保存
- **复制/导出 Markdown 大纲**：头部一键将当前会话的完整大纲复制为格式化 Markdown 树，便于归档与分享
- **会话切换自动同步**：与 DSH 会话生命周期完全一致，新会话即时清空，无任何残影
- **多语言**：自动跟随 DSH Web 界面语言（中文 / 英文 / 西班牙语）
- 明暗主题 100% 自动跟随 DSH Web GUI

## 安装

```sh
dsh plugin --profile web add dsh-chat-toc
```

重启 `dsh web`，多轮对话后聊天区右缘即出现目录窄条。

> 本地开发时可用 `dsh plugin --profile web add link:/path/to/dsh-chat-toc` 以链接方式安装，修改源码后 `npm run build` 并刷新页面即可生效。
