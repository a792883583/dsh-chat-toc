# dsh-chat-toc (DSH 对话目录与原生小地图增强)

[English](README.en.md) · [Español](README.es.md)

DSH Web GUI 的对话导航与大纲增强插件：**深度赋能官方原生 Turn Rail 导航轨**，告别冗余平行的第二条轨道，100% 融入原生界面。提供悬停卡片双向预览（用户提问 + AI 核心回答）、单条收藏与金光高亮、跨会话持久化、右上角原生扁平小工具栏（搜索 / 收藏过滤 / Markdown 大纲导出）。

## 功能特性

- **100% 原生融合与零视觉负担**：
  - 彻底移除冗余并排的彩色指示条，不破坏界面原有留白；
  - 深度赋能 DSH 官方自带的右侧消息刻度轨道，使原生小地图具备旗舰级功能。

- **自主稳定悬停卡片（带防抖，绝不闪退）**：
  - **双向内容呈现**：鼠标滑过官方轨道上的任意刻度，优雅弹出自研高质量预览卡片，清晰呈现 **👤 用户提问** 与 **🤖 AI 核心回答**；
  - **300ms 黄金防抖**：鼠标从轨道向左平移移入卡片时，卡片保持稳定悬浮，可从容选中文字或点击操作按钮，彻底解决原生卡片离开即闪退的痛点；
  - **一键收藏（⭐）与复制（📋）**：每张卡片右下角直接内嵌操作区，点击一键收藏该轮对话，或一键复制该轮问答全部正文。

- **跨会话永久持久化（Session-Scoped Storage）**：
  - 基于稳定的 **会话 ID (Session ID) + 消息全局唯一指纹 (chatAnchorKey)** 进行隔离持久化；
  - 刷新页面、关掉浏览器重新打开，收藏状态永远不丢；只有在会话被主动删除或归档时才清除。

- **右上角扁平极简工具条（原生排版流）**：
  - 优雅内嵌于右上角操作区（紧邻 Session 日志按钮），与界面浑然天成，绝不遮挡任何侧边面板或产生双滚动条；
  - **🔍 关键词快速搜索**：点击向左平滑展开紧凑搜索输入框，输入关键词即时在轨道上高亮匹配刻度，并自动平滑滚动定位到第一条结果，按 `Esc` 随时收起；
  - **⭐ 仅看收藏过滤**：点击一键开启收藏过滤模式，未收藏刻度自动半透明淡化，已收藏刻度呈现 **22px 醒目金黄加宽长条 + 金色粒子微光晕**，全轨重要结论一览无余；
  - **📋 复制 Markdown 结构大纲**：一键将整场对话的所有提问与角色大纲导出为格式化 Markdown 树，便于快速归档与分享。

- **多语言与明暗主题自适应**：
  - 自动跟随 DSH Web 界面语言（中文 / 英文 / 西班牙语）；
  - 100% 完美适配 DSH Web 的浅色（Light）与深色（Dark）主题模式。

## 安装方式

```sh
dsh plugin --profile web add dsh-chat-toc
```

安装或更新后，刷新 `dsh web` 页面即可无缝体验。

> 本地开发时可用 `dsh plugin --profile web add link:/path/to/dsh-chat-toc` 以链接方式安装，修改源码后 `npm run build` 并刷新页面即可生效。
